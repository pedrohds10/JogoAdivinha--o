adivinha
jogo de Adivinhação em Python

Um jogo de console simples e divertido onde o jogador tenta adivinhar um número secreto entre 1 e 100 dentro do limite de 7 tentativas. A cada palpite incorreto, o programa fornece dicas indicando se o número secreto é maior ou menor.

Funcionalidades

Geração aleatória de um número entre 1 e 100 a cada rodada.

Sistema de controle de tentativas (máximo de 7 chances).

Dicas dinâmicas ("O número é maior" / "O número é menor").

Validação de entrada para garantir que o usuário digite apenas números válidos.

Como Jogar

O programa escolherá um número secreto entre 1 e 100.

Digite seu palpite quando solicitado e pressione Enter.

O jogo informará se o número correto é maior ou menor que o seu palpite.

Você vence se acertar em até 7 tentativas; caso contrário, o jogo revela o número secreto.

Tecnologias Utilizadas

Python 3: Linguagem principal utilizada no desenvolvimento.

Módulo random: Utilizado para a geração do número aleatório.
